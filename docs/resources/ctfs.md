# CTFs & Challenges

## Suggested progression

Do them in this order. Each builds on the previous.

| # | Challenge | What you practice | Link |
|---|---|---|---|
| 1 | OverTheWire Bandit | Linux fundamentals | [overthewire.org](https://overthewire.org/wargames/bandit/) |
| 2 | ICSim exercises | CAN sniffing, injection, replay | [zombieCraig/ICSim](https://github.com/zombieCraig/ICSim) |
| 3 | exploit.education Phoenix | Stack overflows, format strings, heap | [exploit.education](https://exploit.education/phoenix/) |
| 4 | Azeria Labs ARM exercises | ARM assembly and exploitation | [azeria-labs.com](https://azeria-labs.com/writing-arm-assembly-part-1/) |
| 5 | Microcorruption | Embedded exploitation (MSP430) | [microcorruption.com](https://microcorruption.com/) |
| 6 | DVRF / DVAR | Firmware RE on ARM/MIPS | [DVRF](https://github.com/praetorian-inc/DVRF), [DVAR](https://blog.exploitlab.net/2018/01/dvar-damn-vulnerable-arm-router.html) |
| 7 | ChipWhisperer Labs | Power analysis, voltage glitching | [chipwhisperer.readthedocs.io](https://chipwhisperer.readthedocs.io/) |
| 8 | RHme (Riscure Hack Me) | SCA + FI on real hardware | [Riscure/Rhme-2016](https://github.com/Riscure/Rhme-2016) |
| 9 | DEF CON CHV CTF | Full automotive security | [carhackingvillage.com](https://www.carhackingvillage.com/) |
