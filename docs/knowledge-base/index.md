# Knowledge Base

Numbered chapters covering automotive security topics. Each chapter curates the best existing resources and fills gaps with lab suggestions.

For vehicle network protocols and diagnostics, the [icanhack.nl Knowledge Base](https://icanhack.nl/knowledge-base/networks/introduction/) is the definitive reference. For embedded hardware hacking methodology, see the [VoidStar Security Roadmap](https://voidstarsec.com/roadmap/).
